1向量与线性组合

vector · linear combination · span · basis

一个向量是一列数，也是一支箭头。整个线性代数只追问一件事：把这些箭头按不同的倍数加起来，能到达哪些地方？

向量是一份配方

在 R2 里，(3, 1) 的意思是"向东 3 步、向北 1 步"。在 R4 里就是四个数。数几个数，就是几维——几何图像只是它的一个壳。

真正重要的是它只允许两种操作：两个向量可以相加，一个向量可以乘一个数。这两条就是"线性" linear 的全部来源，其余性质都是它们推出来的。

定义 · definition

向量 vector 是一列数；它的合法操作只有加法 addition 与数乘 scalar multiplication。

A vector is a list of numbers. You may add two vectors, and you may scale one by a number.

把箭头加起来

给几个向量各配一个系数，加起来，得到的东西叫线性组合 linear combination：

c1v + c2w

系数可以是任何实数：正数、负数、零。于是问题变成：所有可能的搭配，能覆盖多大的地方？

两个不共线的向量，能拼出平面上的每一个点——它们张成 span 整个平面，也叫线性无关 linearly independent。一旦共线，所有组合都挤在那条线上，就变成线性相关 dependent。

定义 · definition

一组向量的张成 span = 它们全部线性组合的集合。若其中某个向量能由其余的表示，这组向量线性相关 dependent；否则线性无关 independent。

Span is the set of every linear combination. A set is dependent when one of its vectors is already reachable from the others.

平面上放三个向量，一定相关。理由很朴素：要让 c1v1 + c2v2 + c3v3 = 0 成立，是两个方程、三个未知数——未知数比约束多，总有一组不全为零的解。

换一组基，坐标就变了

两个不共线、又能张成整个平面的向量，配得上一个名字：基 basis。用一组基去表示一个向量，那组系数就是它的坐标 coordinates。

标准基 e1 = (1, 0)、e2 = (0, 1) 只是最省事的选法。同一个点 (3, 5)，在基 (1, 1)、(1, −1) 下的坐标是 (4, −1)，因为 4(1, 1) + (−1)(1, −1) = (3, 5)。

定义 · definition

基 basis = 一组线性无关、且能张成整个空间的向量。维数 dimension = 基里向量的个数（同一个空间，基怎么选，个数都不变）。

Coordinates are not the vector itself. They are that vector's coefficients in a chosen basis.

v = (1, 2)，w = (2, 4)，它们张成什么？

答一条直线 y = 2x。因为 w = 2v，任何组合 c1v + c2w = (c1 + 2c2)v 都躺在 v 的方向上。它们线性相关，秩为 1。

点 (3, 5) 在基 (1, 1)、(1, −1) 下的坐标是多少？

答(4, −1)。解 c1(1, 1) + c2(1, −1) = (3, 5)：第一式 c1 + c2 = 3，第二式 c1 − c2 = 5，两式相加得 c1 = 4，回代得 c2 = −1。

为什么平面上三个向量一定线性相关？

答求 c1v1 + c2v2 + c3v3 = 0，展开后是两个方程、三个未知数。齐次方程组未知数多于方程，必有非零解，也就是能找到一个向量被另外两个表示出来。

这条推理可以推广成一句通用判据：空间里放超过维数个向量，必然相关。

2矩阵就是变换

matrix · linear transformation · composition

矩阵不是一张数表，它是一个动作：抓住平面上每一个点，按同一套线性规则搬到别处。

只看基向量去了哪

线性变换 linear transformation 守两条规矩：原点不动；直线搬过去还是直线，网格线保持平行、等距。所以只要知道两个基向量被送到哪里，整个平面就被完全确定了。

A 的第一列 = e1 的去处，第二列 = e2 的去处：

A = abcd，Ae1 = ac，Ae2 = bd

于是任意点 (x, y) 的像就是 x 乘第一列、加 y 乘第二列。矩阵乘向量的规则不是凭空规定的——它就是"按坐标把列拼起来"这句话的缩写。

四种常见动作

  • 旋转 rotation：cos θ−sin θsin θcos θ，长度全部不变，det = 1。
  • 缩放 scaling：对角阵，两个方向各放大几倍，det 是两个倍数的乘积。
  • 剪切 shear：1k01，把正方形推成平行四边形，面积不变，det = 1。
  • 投影 projection：1000，把整个平面压到 x 轴上，det = 0。

最后一种值得停下来看：投影把一整条竖线上的点全部压到同一个点上。两个不同的输入有同一个输出，这件事不可逆——你没法从 (2, 0) 反推出原来是在 (2, 5) 还是 (2, −3)。信息丢了，就没法倒车。这就是"不可逆"在几何上的意思，也是 det = 0 的意思。

复合：顺序要反着读

先做 B，再做 A，写成 AB。写在最右边的是最先动手的那个，因为它最先碰到 x：

A(Bx) = (AB)x

所以矩阵乘法不可交换 AB ≠ BA——先穿袜子再穿鞋，和反过来，结果不一样。计算规则是：AB 的第 i 行第 j 列，等于 A 的第 i 行点乘 B 的第 j 列。

举个例子。逆时针转 90° 记作 R，关于 x 轴翻转记作 F：

R = 0−110，F = 100−1，FR = 0−1−10

验一下：e1 先转成 (0, 1)，再翻成 (0, −1)，正好是 FR 的第一列。

剪切 1101 把 e2 = (0, 1) 送到哪？

答(1, 1)。第二列就是它：11。几何上它把竖直方向整体往右推了一格，所以正方形变成了平行四边形，但面积不变。

先转 90°，再关于 x 轴翻转，合成矩阵是什么？

答FR = 0−1−10。两个办法都能得：一是直接算 FR；二是看两个基向量的遭遇——e1 → (0, 1) → (0, −1)，e2 → (−1, 0) → (−1, 0)，两列一拼就是答案。

为什么 det = 0 的变换一定不可逆？

答det = 0 意味着两列线性相关，整个平面被压进一条线（极端情况下压成一个点）。线上一段有无穷多个点，它们互相挤在一起——从像你分不清它们原来是谁。代数上说：方程 Ax = 0 有非零解，所以 A 有零空间，映射不是一一的。

3线性方程组

Ax = b · rank · null space

同一个式子 Ax = b，有两种看法：一行看是直线的交点，一列看是向量的拼装。两种都要会在手上。

行图像：每条方程是一条线

每个方程都是一个限制。x + y = 3 是平面上一条直线；再给一个方程，又一条线。解就是它们共同的交点——所以在二维里，两个方程一般给一个解。

三种结局也一眼看得出：两线交于一点（唯一解）、平行（无解）、重合（无穷多解）。

列图像：b 能不能由两列拼出来

把 A 横着切开看，Ax 是两列的线性组合：

Ax = x1列 1 + x2列 2

于是"解方程"变成"找那组拼装配方"。b 落在两列张成的平面里，就有解；两列共线时，b 必须正好落在那条线上——否则怎么配都够不着。

三种结局，一句话说清

  • det(A) ≠ 0：两列不共线，能拼出整个平面，任何 b 都有唯一解。
  • det(A) = 0，且 b 在列空间里：有无穷多解，它们差在一个零空间的方向上。
  • det(A) = 0，且 b 不在列空间里：无解。
定义 · definition

零空间 null space = 所有满足 Ax = 0 的 x。列空间 column space = A 所有列的线性组合构成的集合。

The rank of A is the dimension of its column space; the null space collects everything A crushes to zero.

秩 rank 是列空间的维数——它说"像有多少维"。零空间的维数叫零化度 nullity——它说"多少维被压没了"。对 n 列的矩阵，两者加起来恒等于 n：

rank + nullity = n

这条等式就是守恒律：进去的维度，要么留在像里，要么落进零空间，不会凭空消失。

消元法在做什么

高斯消元 Gaussian elimination 就是反复把一行减去另一行的倍数。每一步都对应一个可逆的变换，所以解集不变；做到上三角，再从下往上回代。

消元过程中若出现 0 = 0，说明方程之间有冗余——解不唯一。若出现 0 = 非零，说明条件互相矛盾——无解。

x + y = 3 与 2x + 2y = 6，有几个解？

答无穷多。第二个方程就是第一个的两倍，两条线完全重合。系数矩阵 1122 的 det = 0，列共线，秩为 1，解是一条直线上的所有点。

x + y = 3 与 x + y = 4 呢？

答无解。两线平行，交不出来。用列图像看更清楚：b = (3, 4) 不在两列张成的那条线上。

A = 1224 的零空间和列空间各是什么？

答零空间：解 x1 + 2x2 = 0，得到所有 t(−2, 1)，是一条过原点的直线，nullity = 1。列空间：两列成比例 (1, 2) 与 (2, 4)，张成的是沿 (1, 2) 的那条直线，rank = 1。两维加起来正好是 n = 2。

4行列式

determinant · area · orientation

行列式只有一个意思：这个变换把面积放大了几倍。符号是朝向有没有翻。

面积和朝向

单位正方形经过 A 之后变成一个平行四边形。它的面积就是 |det A|。det 为正，说明朝向没变——原来逆时针的还在逆时针；det 为负，说明朝向翻了，像照镜子。

二阶的公式是 det A = ad − bc。它不是背出来的：两列 (a, c) 与 (b, d) 张成的平行四边形，面积正好是这个式子。三维里同一个故事讲体积，n 维里讲 n 维体积。

定义 · definition

行列式 determinant 是线性变换对面积（体积）的缩放倍数，带符号。符号表示朝向 orientation：正为保持，负为翻转。

The determinant scales area; its sign tells whether orientation is preserved or flipped.

三种命运

  • det = 0：空间被压进更低一维，面积归零，不可逆。
  • 0 < |det| < 1：面积缩小。
  • |det| > 1：面积放大。
  • det < 0：面积照常缩放，但朝向翻转。

行列式还是乘法性的：

det(AB) = det(A) det(B)

这很自然——先 B 缩放一次，再 A 缩放一次，总倍数是两者相乘。顺便得到一个常用结论：det(A−1) = 1 / det(A)。

手算：三条性质就够

  • 交换两行（或两列），行列式变号。
  • 某一行乘以 k，行列式乘以 k。
  • 把一行的倍数加到另一行上，行列式不变。

前两条是定义直接给的，第三条正是消元法能用的原因：整条消元过程不改变 det，最后化成上三角，det 就是对角线元素的乘积。三角矩阵的行列式因此格外好算：

det 210031004 = 2 × 3 × 4 = 24

det 1234 是多少？面积和朝向呢？

答1×4 − 2×3 = −2。面积缩放 2 倍，符号为负，所以朝向翻转——两列一个指向第一象限、一个指向第三象限，夹角是钝的。

det A = 3，det B = 2。求 det(AB) 与 det(A−1)。

答det(AB) = 3 × 2 = 6。det(A−1) = 1/3，因为 A 放大 3 倍，倒回去就要缩小 3 倍。

det A = 0 时，下面哪条一定成立：A 可逆 / Ax = b 有唯一解 / A 的列线性相关？

答只有第三条。det = 0 等价于列线性相关、零空间非平凡、不可逆、秩低于 n——这一串说法是同一件事的五个名字。Ax = b 可能有解，也可能没有，但一定不会"唯一"。

5特征向量

eigenvector · eigenvalue · diagonalization

一个变换会把大多数向量扭向别处，只有少数几个方向它动不了——那些就是特征向量。

方向不变，只伸缩

对着一个矩阵反复问同一个问题：有没有哪个非零向量 v，变换之后只是变长变短，方向还在同一条线上？如果有，那个伸缩倍数就是它的特征值。

Av = λv

特征向量是变换的骨架：它们指出哪些方向是稳定的。绝大多数向量会被慢慢拽向特征值最大的那个方向，因为那个方向每一步放大得最多。

定义 · definition

特征向量 eigenvector v ≠ 0 与特征值 eigenvalue λ 满足 Av = λv。λ 可以是负数（方向反过来），也可以是复数。

An eigenvector is a direction the transformation only stretches; the eigenvalue is the stretch factor.

怎么算

把 Av = λv 移项：(A − λI)v = 0。我们要的是非零的 v，所以 A − λI 必须把某个非零向量压成零——它必须不可逆：

det(A − λI) = 0

这个式子叫特征方程 characteristic equation。二阶展开成二次方程，就顺手拿到两个速记关系：

λ1 + λ2 = tr(A)，λ1λ2 = det(A)

算完回头用这两条验算，比重新展开一遍省事得多。

对角化：把变换摆正

如果两个特征向量线性无关，把它们当列拼成 P，对角线放特征值拼成 D，就有

A = PDP−1

意思是：先换到特征向量做坐标轴，在那里变换只是沿坐标轴各拉伸 λ1、λ2 倍，再换回来。幂次立刻变得简单：

An = PDnP−1

Dn 只是把对角线各取 n 次方。所以长期行为完全由特征值决定：|λ| 最大的那个方向会吞掉其他所有方向。马尔可夫链收敛、斐波那契数列的通项、微分方程的解，背后都是这一条。

复数特征值 = 旋转

旋转 90° 的矩阵 0−110：tr = 0，det = 1，特征方程 λ2 + 1 = 0，得到 λ = ±i。没有实特征向量——每个方向都被转了 90°，没有方向留下来。复数特征值出现，几何上就意味着"在转"。

A = 2003 的特征值和特征向量？

答λ1 = 2 配 e1 = (1, 0)，λ2 = 3 配 e2 = (0, 1)。对角矩阵不用算——它本来就在特征方向上，只是沿轴缩放。

A = 1101 呢？

答λ = 1 是二重根（trace 2、det 1）。但 A − I = 0100，零空间只有 (1, 0) 一条线，只能找到一个独立特征向量。几何重数 1 < 代数重数 2，所以不可对角化——这就是"剪切"和"纯缩放"的本质区别。

为什么旋转 90° 没有实特征向量？

答每个非零方向都被转到了垂直的方向，没有一条线被映射回自己。Av = λv 要求像和原向量同向（或反向），而旋转做不到。所以只能在复数里找特征值：λ = ±i，模长 1，正好对应"长度不变，只转角度"。

6正交与最小二乘

dot product · projection · normal equations

"最近"这个词要先有垂直才说得清楚。这一章把距离变成一道可以直接算的题。

点积：投影了多少

a · b = a1b1 + a2b2 = |a| |b| cos θ

点积为零，就是垂直（正交 orthogonal）。点积为正，夹角小于 90°；为负，大于 90°。它本质上在回答：b 顺着 a 走了多远。

投影：把 b 拆开

把 b 拆成两块：沿着 a 的分量 p，和垂直于 a 的残差 e = b − p。沿着 a 的所有点里，p 离 b 最近。

p = a · ba · a a

为什么它最近？因为 b、p、e 构成直角三角形，斜边永远比直角边短。往旁边挪一点，距离就变成斜边了。所以"最近"的判据就是 b − p ⊥ a。

最小二乘：方程无解时怎么办

数据比参数多的时候，Ax = b 通常无解——b 不在列空间里。这时不求精确解，求让误差最小的那个：

minx ‖b − Ax‖

几何上就是上一节的投影，只是把"一条直线"换成"整个列空间"：把 b 投影到列空间上，落点就是 Ax̂。条件仍然是残差垂直：AT(b − Ax) = 0，整理成正规方程 normal equations：

ATA x = AT b

正交基的便宜

如果基向量两两正交，求坐标就不必解方程组了——一个点积就够：ci = (v · ui) / (ui · ui)。系数之间互不干扰，各算各的。

格拉姆–施密特 Gram–Schmidt 就是把任意一组基改造成正交基的步骤：拿第二个向量，减掉它在第一个方向上的投影；拿第三个，减掉它在前面所有方向上的投影。每减一次，就多出一个正交方向。

这件事听起来朴素，但它是傅里叶级数、QR 分解、数据压缩的共同骨架——把一个向量拆成一堆互不干扰的分量，然后分开处理。

(1, 1) 与 (1, −1) 正交吗？

答正交。点积 1×1 + 1×(−1) = 0。它们的长度都是 √2，所以 {(1,1)/√2, (1,−1)/√2} 还是一组标准正交基 orthonormal basis。

(2, 3) 在 (1, 0) 上的投影是多少？

答(2, 0)。投影公式：(a·b / a·a)a = (2/1)(1,0) = (2,0)。残差 (0, 3) 果然垂直于 (1, 0)。

最小二乘的解为什么满足 ATAx = ATb？

答因为残差 b − Ax 必须垂直于整个列空间。垂直于列空间，就是垂直于 A 的每一列，写成矩阵就是 AT(b − Ax) = 0。展开即得正规方程。

这也解释了为什么拟合直线的"残差和为 0、直线过重心"：常数那一列全是 1，和它正交就是残差求和为零。

各方向按倍数伸缩，det 等于各倍数之积。
投影projection
把空间压到更低维的子空间上；det = 0，不可逆。
反射reflection
像照镜子，朝向翻转，det = −1。
复合composition
先做一个变换再做另一个；对应矩阵乘法，顺序要反着读。
转置transpose
行列互换，记作 Aᵀ。

方程组

线性方程组system of linear equations
一组线性方程要同时满足；写成矩阵形式就是 Ax = b。
增广矩阵augmented matrix
把 b 接到 A 右边，写成 [A | b]，方便一起做行变换。
消元法Gaussian elimination
用行变换化成上三角，再回代求未知数。
行最简形reduced row echelon form
消到再也不能消的形状，非零行的个数就是秩。
秩rank
列空间（也等于行空间）的维数，说明"像有多少维"。
零空间null space
所有被 A 压成零的向量，即 Ax = 0 的全部解。
零化度nullity
零空间的维数；rank + nullity = 列数。
列空间column space
A 的所有列的线性组合，也就是所有可能的像。
可逆invertible
存在 A⁻¹；等价于 det ≠ 0、列线性无关、零空间只有零。
逆矩阵inverse matrix
把变换倒回去的那个矩阵，A·A⁻¹ = I。

行列式与特征

行列式determinant
面积（体积）的缩放倍数，带符号；符号表示朝向是否翻转。
迹trace
对角线元素之和，等于全部特征值之和。
特征向量eigenvector
变换后方向不变的向量，Av = λv。
特征值eigenvalue
特征向量被伸长的倍数 λ，可以是负数或复数。
特征方程characteristic equation
det(A − λI) = 0，它的根就是特征值。
特征多项式characteristic polynomial
det(A − λI) 展开后的多项式。
对角化diagonalization
A = PDP⁻¹，把变换换成"沿特征方向各伸缩各的"。
代数重数algebraic multiplicity
某个 λ 在特征多项式里作为根出现的次数。
几何重数geometric multiplicity
某个 λ 对应的独立特征向量个数；不够就无法对角化。

正交与拟合

点积dot product
a·b = |a||b|cosθ，衡量 b 在 a 方向上投影了多少。
正交orthogonal
点积为零，互相垂直。
标准正交orthonormal
两两正交，且每个向量长度都是 1。
投影向量projection
b 在 a 方向上的分量：(a·b / a·a) a。
残差residual
b 减去投影之后剩下的垂直部分，b − Ax。
最小二乘least squares
方程无解时，让 ‖b − Ax‖ 最小的那个 x。
正规方程normal equations
AᵀAx = Aᵀb，最小二乘解满足的方程。
格拉姆–施密特Gram–Schmidt
把任意一组基改造成正交基的步骤：每次减掉已有方向上的投影。
